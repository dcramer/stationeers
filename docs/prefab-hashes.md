# Stationeers prefab hashes

Complete alphabetical catalog of the **1,788** prefab names and signed 32-bit hashes in Stationpedia game data version `0.2.6367.27532`. The source snapshot is the game-generated [`Stationpedia.json`](https://github.com/FlorpyDorpinator/FlorpyDorp-IC10-Language-Support/blob/d923666f4527ce5809a6dfe21db0cf5b23be0894/data/Stationpedia.json) committed on 2026-07-05.

This deliberately includes every entry in the Stationpedia `pages` array, not only prefabs beginning with `Item`. Structures, kits, ores, plants, access cards, and other hash-addressable game objects are included so a category naming convention cannot silently omit an object.

Use the numeric value directly where IC10 expects a prefab hash, or use `HASH("PrefabName")` to make a script self-documenting. Example: `HASH("StructureWeatherStation")` is `1997212478`.

> Hashes are version-sensitive. This catalog is a captured reference for the version above, not a claim about a later Stationeers build. Check the in-game Stationpedia after an update.
